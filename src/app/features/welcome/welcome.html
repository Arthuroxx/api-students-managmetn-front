Student management, simplified

A calmer way to manage student records.

The foundation for a focused, accessible student management experience. Built with Angular 22, strict TypeScript, and a neutral design system that stays out of the way.

  • Signals-first state Predictable local state with derived values and no duplicated sources of truth.
  • Accessible by default Semantic landmarks, visible focus, keyboard support, and reduced-motion handling.
  • Strict quality gates TypeScript strict mode, ESLint, Prettier, and Vitest keep the codebase dependable.
